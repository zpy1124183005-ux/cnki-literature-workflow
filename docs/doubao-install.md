# 在豆包工作中安装和使用

适用：豆包电脑版的“工作任务”／豆包工作。包格式已按 `SKILL.md` 入口要求整理；尚未在豆包客户端实际安装及完成知网采集验证。

## 下载

[直接下载技能 ZIP](https://github.com/zpy1124183005-ux/cnki-literature-workflow/releases/latest/download/cnki-literature-workflow.skill.zip)

选择这个发布附件，ZIP 根目录有 `SKILL.md` 和配套脚本。GitHub 仓库的“Code → Download ZIP”会多包一层仓库目录，若使用该方式，应先解压并选择含 `SKILL.md` 的技能目录。

## 让豆包协助下载和安装

可把下面这段话发给朋友，让她复制到豆包工作：

> 请下载这个知网题录技能包：
> https://github.com/zpy1124183005-ux/cnki-literature-workflow/releases/latest/download/cnki-literature-workflow.skill.zip
> 将它作为 cnki-literature-workflow 技能导入，并读取 SKILL.md。若当前版本不支持通过对话直接安装，请将 ZIP 下载到本机，告诉我在哪里选择“上传技能”，不要仅阅读网页后声称已安装。安装后先检查浏览器操作、文件写入和 Node.js 20 或以上版本是否可用，再用包内虚构示例验证离线整理。先不检索知网，告诉我真实执行结果和缺少的能力。

这是给豆包执行的请求，不代表任意版本都能通过链接自动完成安装。完成与否以技能列表出现该技能及实际示例执行结果为准。

## 手动导入

1. 在豆包工作中进入技能管理页。常见入口为侧栏“技能 · 连接器 · 伙伴”（部分版本称“插件 · 技能 · 伙伴”），以客户端实际界面为准。
2. 选择技能页的“添加／新建 → 上传技能”，选择下载的 ZIP。若当前界面只接收文件夹，先解压，再选择直接包含 `SKILL.md` 的目录。
3. 确认识别出的技能名为 `cnki-literature-workflow`。回到工作任务，通过技能选择器选中它；支持斜杠调用的版本可输入 `/` 查找。
4. 让豆包先运行 SKILL.md 的虚构示例，预期为 5 条观察记录、4 条核心来源并集、3 条阅读候选。确认输出文件真实存在。

## 开始第一次知网任务

如果要使用本机浏览器登录态或学校的访问环境，选择能操作本机浏览器的本地电脑模式。朋友需要自行具备相应知网访问条件；本技能不附带任何账号或机构权限。

示例任务：

> 使用 cnki-literature-workflow。请在知网按“主题＝乡村治理共同体”检索学术期刊，年份不限。分别采集 CSSCI 与北大核心，按知网编号去重并核对交集、并集；总目排除，书评标记保留。每页保存断点，遇到验证码、空页或异常时停止并告诉我。请记录当次真实命中数，不套用历史案例数字，导出题录、阅读候选、期刊汇总和统计文件。

安装技能只添加工作方法。实际采集还需要可操作的浏览器；随包离线脚本需要 Node.js 20 或以上。`browser/collect-stage.js` 是 Tabbit 模板，不能直接在普通 Node.js 或没有 `page` 对象的豆包环境执行。豆包应使用自己的工具接口或说明当前缺少的能力。
